## Что проверил и проблем не нашёл

- **Секретов нет.** Поиск по `api_key|secret|token|password|PRIVATE KEY|gho_|ghp_|sk-` дал только `id-token: write` в `.github/workflows/deploy.yml` (это GitHub OIDC-разрешение для деплоя, не секрет) и `js-tokens` в `package-lock.json` (имя пакета). В истории Git секретов нет.
- **Сборка и типы:** `tsc -b && vite build` проходит без ошибок, 39 модулей.
- **Единообразие оформления:** отступы двух пробелов, табов нет, CJK/битых символов нет, цвета и типографика выдержаны в палитре `zinc`/`sky`, переводы строк CRLF стабильны.
- **Циклов в дереве слоёв нет:** `parentId` задаётся только из существующих родителей, операции переподключения родителя в UI нет, поэтому бесконечный цикл в `visibleAt` недостижим.
- **Координаты вложенных фигур корректны:** `renderShape(child, shape.x, shape.y)` переносит дочерние фигуры в систему координат родителя, `startMove` двигает всё поддерево `subtreeIds` целиком.
