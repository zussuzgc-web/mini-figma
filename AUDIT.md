## Проверено, проблем не найдено

- **Секретов нет.** Поиск по `api_key|secret|token|password|PRIVATE KEY|gho_|ghp_|sk-` дал только `id-token: write` в `.github/workflows/deploy.yml` (GitHub OIDC-разрешение для деплоя, не секрет) и `js-tokens` в `package-lock.json` (имя пакета). В истории Git секретов нет.
- **Undo-стек корректен.** `pushHistory` кладёт снимок до изменения, `undo` берёт последний снимок и текущее состояние — в `future`. Обрезание до `MAX_HISTORY` отбрасывает самые старые записи и не теряет последнее действие.
- **Циклов в дереве слоёв нет:** `parentId` задаётся только из существующих родителей, операции переподключения родителя в UI нет, поэтому бесконечный цикл в `visibleAt` недостижим.
- **Координаты вложенных фигур корректны:** `renderShape(child, shape.x, shape.y)` переносит дочерние фигуры в систему координат родителя, `startMove` двигает всё поддерево `subtreeIds` целиком.
- **Оформление единообразно:** отступы двух пробелов, табов нет, CJK и битых символов нет, палитра `zinc`/`sky` выдержана, переводы строк стабильны.
- **P0 не найдено.**

## Как проверял

1. `npm.cmd run build` (`tsc -b && vite build`) — без ошибок, 39 модулей.
2. `npm.cmd run preview -- --port 4180`, затем HTTP-проверка `/mini-figma/`, JS и CSS: все 200, MIME-типы верные.
3. Headless Chrome через CDP: сборка `consoleErrors`, `Runtime.exceptionThrown`, `Log.entryAdded` — пусто после правок. До правок в консоли были `Unable to preventDefault inside passive event listener invocation` и 404 на `/favicon.ico`.
4. Сценарии в реальном браузере через `Input.dispatchMouseEvent` / `dispatchKeyEvent`:
   - рисование прямоугольника, фрейма и эллипса горячими клавишами; дерево слоёв `Frame depth=0 / Ellipse depth=1`;
   - выбор фигуры, ввод `W = 0` → после blur значение `1`; один Ctrl+Z возвращает `220`, redo возвращает `1`;
   - клик без перетаскивания не добавляет запись в историю;
   - ввод имени с пробелами, blur коммитит, один Ctrl+Z возвращает исходное имя;
   - Backspace в текстовом поле не удаляет фигуру;
   - зум колесом, панорама пробелом, double-click fit all — трансформации применяются;
   - Delete удаляет выбранное, Ctrl+Z возвращает;
   - вставка PNG 1200×600 → 600×300 (пропорции сохранены); файл 3 МБ и не-изображение отклонены; Ctrl+Z удаляет картинку.
